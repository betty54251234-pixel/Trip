# TripPath

개인 해외여행용 무료 PWA 프로토타입.

## 핵심 원칙
- 일정 순서는 사용자가 정한다.
- 동선 최적화는 자동 변경하지 않고 추천만 한다.
- 예약/고정 일정은 순서 최적화의 경계점으로 유지한다.
- Day 여러 개를 지도에서 동시에 켜서 비교할 수 있다.
- 실제 도보 경로는 openrouteservice `foot-walking`을 사용한다.

## 실행
정적 파일이므로 GitHub Pages에서 바로 배포할 수 있다.
로컬 테스트는 폴더에서 간단한 HTTP 서버를 띄우면 된다.

```bash
python3 -m http.server 8000
```

## 실제 도보 경로 활성화
1. openrouteservice에서 무료 API 키 발급
2. 앱 우측 상단 설정에서 키 입력
3. 키는 브라우저 localStorage에만 저장

## 현재 기능
- 여행 생성
- 날짜 기반 Day 자동 생성
- Day별 장소 추가/수정/삭제
- 지도 클릭으로 좌표 지정
- 예약/고정 일정과 시간 표시
- 일정 수동 위/아래 이동
- Day 1+2+3 등 복수 지도 표시
- ORS 사용 시 실제 도보 경로/거리/시간 표시
- 예약 일정 사이 자유 장소만 최적화 추천
- 추천 전/후 거리와 시간 비교
- 사용자가 승인할 때만 추천 순서 적용
- PWA manifest/service worker
