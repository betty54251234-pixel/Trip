# TripPath v2

개인 해외여행용 무료 PWA.

## 핵심 원칙
- 일정 순서는 사용자가 정한다.
- 동선 최적화는 자동 변경하지 않고 **추천만** 한다.
- 예약/고정 일정은 순서 최적화의 경계점으로 유지한다.
- Day 여러 개를 지도에서 동시에 켜서 비교할 수 있다.
- 실제 도보 경로는 openrouteservice `foot-walking`을 사용한다.

## v2 변경점
- iPhone에서 날짜 입력칸 겹침 수정
- 입력창 터치 시 Safari 자동 확대 방지, 일반 화면 페이지 줌 제한
- 지도 안에서는 Leaflet 확대/축소 유지
- 기본 지도를 밝고 단순한 CARTO Positron 계열로 변경
- 장소명 검색 → 검색 결과 선택 → 좌표 자동 지정
- 지도에서 직접 찍기는 보조 기능으로 유지
- ORS 키가 없거나 경로 호출이 실패하면 직선 연결선을 표시하지 않음
- Day별 색상: 빨강 → 주황 → 초록 → 파랑 → 남색 → 보라 → 핑크 → 갈색 → 청록…
- 핀은 Day 색 + 검정 외곽선
- 실제 도보 경로도 검정 외곽선 + Day 색상 선
- 앱 아이콘을 루트 폴더로 옮겨 iPhone GitHub 업로드가 쉬워짐
- 서비스워커 v2로 갱신하여 기존 캐시를 자동 교체

## 실제 도보 경로 / 장소 검색 활성화
1. openrouteservice 무료 API 키 발급
2. 앱 우측 상단 설정에서 키 입력
3. 키는 이 브라우저의 localStorage에 저장되고 GitHub 소스에는 포함되지 않음

## GitHub Pages 업데이트
기존 저장소에 이 폴더 안 파일을 전부 업로드하고 같은 이름 파일은 교체하면 된다.
`icons` 폴더는 없고 아이콘 PNG도 루트에 있어 iPhone에서 한 번에 선택 가능하다.
